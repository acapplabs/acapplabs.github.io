How we work

Our development process

Seven steps every app goes through, from the first idea to updates after release.

  1. 01

    Plan

    Every app starts with a written plan: what it must do well, step by step, with each decision recorded and the reason next to it.

  2. 02

    Design

    We sketch the screens and write the words before the code. If a screen needs a manual, it is redesigned.

  3. 03

    Build

    Native code for each platform. Release builds are small and signed, and every change is kept in version control.

  4. 04

    Translate

    Every text exists in all 14 languages before release, checked by a script so none is missing, with right-to-left layout for Arabic.

  5. 05

    Test on real devices

    Each feature is tried on real phones of different brands and on Android versions from 9 to 17, from a written test list.

  6. 06

    Security review

    We read the code looking for weaknesses, then try to break the app from an attacker's side, on the same Wi-Fi and with crafted files.

  7. 07

    Release and support

    Updates go out through Google Play with a public changelog. Security fixes come first, and important ones must be installed when the app opens.

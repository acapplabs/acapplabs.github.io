Security

Privacy is where we start

How we keep you safe

No account, no server

Wayfile works without sign-up and has no server of ours to send your files to.

Protected transfers

A one-time PIN and an approval on the phone for every computer.

Encrypted passwords

Saved network passwords are locked with Android's hardware-backed key store.

Tested like an attacker

Every release is checked by trying to break it, not only by using it.
